# AI Vector Database

Version: 2.1.0
Status: Active; pgvector enabled

## Current State

PostgreSQL runs on the `pgvector/pgvector:pg16` image. The `vector` extension is enabled. `AiKnowledgeChunk.embedding` is a `vector(1536)` column backed by an HNSW index using cosine distance (`ai_knowledge_chunks_embedding_idx`, `vector_cosine_ops`). Embeddings are generated by the `EmbeddingService` (`text-embedding-3-small`, 1536 dimensions; local hash fallback also produces 1536 dimensions) and written through raw SQL with `::vector` casts. Vector similarity search runs in the database via the `<=>` operator.

## Record Shape

- source document/chunk ID
- lesson/unit/grade/academic year/term scope
- language and content type
- content version and updated timestamp
- embedding provider/model and vector

## Required Operations

- index approved content after publish/import (reindex endpoint)
- delete or invalidate chunks after content deletion/update
- reindex by administrator with audit record
- retrieve only content authorized for the requesting student
- measure retrieval quality, latency, and provider cost
